# 🤝 Just Friends

### A Procedural Scenario Generator for AI Dungeon

**Just Friends** is a lightweight JavaScript script for AI Dungeon that adds variety and replayability through randomized starting scenarios.

## ✨ Features

- **10 Random Scenarios** — Start each new adventure with one of ten possible situations.
- **Procedural Variety** — Different starting circumstances encourage different stories.
- **JavaScript Library** — Contains the supporting logic and scenario content.
- **Replayability** — Discover a different starting situation on subsequent playthroughs.

## 🎮 How It Works

When a new adventure begins, Just Friends randomly selects one of ten predefined scenarios, providing a starting point for the AI storyteller.

From there, the adventure develops through normal AI Dungeon gameplay.

## 🛠️ Platform

- **Platform:** AI Dungeon
- **Language:** JavaScript
- **Primary Component:** Library script
